# Luna-r2

Çocuklar için ev arkadaşı robot Luna'nın ikinci tasarımı (R2).

- **Yüz:** kafadaki dokunmatik AMOLED ekranda, telefon gerekmiyor.
- **Kafa:** sabit. Tepesinde LiDAR, ekranın üstünde tek kamera var.
- **Gövde:** yuvarlak. İki tahrikli teker ve iki sarhoş teker.
- **Parçalar:** hepsi Türkiye'den alınabiliyor.

Yazılım: ROS 2 Humble (Jetson Orin NX), Teensy 4.1 micro-ROS, tarayıcıda çalışan yüz.
